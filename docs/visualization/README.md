# Visualization Overview

This folder documents the visualization techniques for the SIH-OCEAN platform —
the globe, day/night lighting, temperature rendering, ocean currents, isosurfaces,
and colorbars.

## Files

| File | Topic |
|---|---|
| [`globe-rendering.md`](globe-rendering.md) | The "perfect globe" — CesiumJS terrain, imagery, atmosphere, bathymetry |
| [`day-night-lighting.md`](day-night-lighting.md) | Day/night terminator, sun position, atmosphere scattering, light theme |
| [`temperature-overlay.md`](temperature-overlay.md) | Temperature scalar field rendering, colormap LUT, depth slices, animation |
| [`ocean-currents.md`](ocean-currents.md) | GPU particle advection for ocean currents (cesium-wind-layer) |
| [`isosurfaces.md`](isosurfaces.md) | Isosurface extraction (thermoclines, isohalines) via marching cubes |
| [`colorbar-editor.md`](colorbar-editor.md) | Customizable colorbar — palette, min/max, log/linear, opacity |
