# Visual Language

## Composition
Full-screen data field, sparse chrome, contextual panels, depth cues.

## Typography
Editorial: region/phenomenon/analytical statement.
Telemetry: coordinates, timestamp, depth, variable, uncertainty, source.

## Semantic color
Ocean base / model / observation / positive residual / negative residual / uncertainty / selected feature.

Avoid rainbow-for-everything.

## Motion semantics
Camera = analytical scale.
Particles = flow.
Trail = history.
Pulse = live observation.
Morph = data transformation.
Fade = reduced relevance.
Expansion = uncertainty/tolerance.
Split = comparison.

## Test
Every animation must communicate information. If it only looks cool, remove it.
