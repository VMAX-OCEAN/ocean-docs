# Interaction Pattern Library

1. **Ocean as canvas** — full-screen field; controls appear contextually.
2. **Camera = analytical scale** — global → region → feature → observation.
3. **Observation as query primitive** — select float; automatically construct its model context.
4. **Model/observation morph** — model → observation → residual.
5. **Residual-first mode** — E = Model − Observation.
6. **Uncertainty as visual physics** — opacity, texture, contours or envelopes with scientific meaning.
7. **Feature as object** — eddy/front/upwelling becomes selectable.
8. **Temporal feature tracking** — birth → movement → growth → decay.
9. **Contextual panels** — information appears next to the selected phenomenon.
10. **Progressive disclosure** — ocean → region → feature → observation → numerical detail → raw metadata.
