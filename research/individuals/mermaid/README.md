# SIH26067 Research

## Thesis
**Make the ocean itself the interface:** an interactive 4D environment in which users explore, compare, interrogate and understand model + observation data.

DATA → SPATIOTEMPORAL ALIGNMENT → INTERACTION → COMPARISON → DISCOVERY → INSIGHT

## Research rule
For every reference record:
1. What does it do?
2. What interaction does it use?
3. What problem does that solve?
4. What can SIH26067 borrow?
5. What should it not copy?
6. Is it technically feasible?
7. Is it scientifically meaningful?
