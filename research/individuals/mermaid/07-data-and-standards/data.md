# Data + Standards

Study:
- NetCDF
- HDF5
- CSV/tabular observations
- GeoJSON
- CF conventions
- OGC standards
- coordinate systems
- units
- vertical coordinates
- temporal calendars

Pipeline:
raw data → validation → metadata → coordinate normalization → chunking/indexing → co-location → API → GPU representation → visualization

Every result should be traceable to source, variable, timestamp, depth, processing/interpolation method and uncertainty assumptions.
