# Existing Ocean Platforms

## Copernicus MyOcean Pro
https://help.marine.copernicus.eu/en/articles/4794675-main-features-of-myocean-pro-viewer

Study: 4D map, layers, depth/time, profiles, trajectories, histograms, exports, in-situ platforms, particle animations.

**Research implication:** 3D + sliders + profiles is already a mature capability.

## Argovis
https://argovis.colorado.edu/

Study: Argo trajectories, profiles, platform metadata, spatial/time filtering.

**New question:** Can an observation become the entry point into the model?

FLOAT → trajectory → local model volume → prediction → observation → residual.

## Ocean Data View
https://odv.awi.de/

Study: scientific profiles, trajectories and environmental data analysis.

## Esri 3D / Earth Nullschool
Study 3D spatial composition and flow-field perception.

## INCOIS
https://incois.gov.in/

Study Indian oceanographic datasets, operational context and data formats.

## Benchmark conclusion
Existing tools are strong at data access and expert analysis. The research opportunity is the combination of immersive spatial interaction + model/observation fusion + residuals + uncertainty + feature discovery.
