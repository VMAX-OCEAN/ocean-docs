# Research Map

## 01 Scientific problem
Requirements, datasets, users, workflows, constraints.

## 02 Existing ocean platforms
Copernicus MyOcean Pro, Argovis, ODV/webODV, Esri 3D, Earth Nullschool, INCOIS.

## 03 Cross-disciplinary design
Awwwards, Godly, NASA Eyes, Mapbox, The Pudding, games/simulations, architecture.

## 04 Interaction
Ocean-as-canvas, camera-as-scale, observation-as-query, model/observation morphing, residual-first exploration, uncertainty, feature objects, temporal tracking.

## 05 Scientific analytics
Co-location, residuals, anomalies, uncertainty, eddies/fronts/upwelling, trajectory analysis.

## 06 Rendering
WebGPU, ray casting, adaptive sampling, LOD, chunking, GPU analytics.

## 07 Data
NetCDF, HDF5, CF, OGC, provenance, metadata, chunked storage.

## 08 Validation
Prototype experiments, performance tests, user-comprehension tests.

## Core research question
How can a browser transform heterogeneous ocean data from a collection of layers into an interactive 4D analytical environment?
